# 📌 요구사항 요약

12월에 시범적으로 우테코 코치가 사용할 크루원 출석 관리 프로그램을 만들어라
<br/>

# 📝 구현할 기능 목록

### 12월 날짜가 주말이나 공휴일인지 파악하는 기능

- [ ] 주어진 날짜 요일에 맞춰 `Day`를 구성한다.
- [ ] 요일과 공휴일인지를 상태로 가진다.

### 출석부 기능

- [ ] 크루를 출석 처리한다.
    - [ ] 시각에 따라 `지각` / `결석` 여부를 판단한다.
    - [ ] 오늘 이미 출석했는지 판단한다.
    - [ ] 날짜와 요일, 시각, 출석 상태를 출력한다.
- [ ] 크루의 출석 기록을 수정한다.
    - [ ] 수정 가능한지 판단한다.
    - [ ] 기존에 `지각` / `결석`이었다가 바뀐 경우 이를 반영한다.
    - [ ] 

### csv 파일에서 정보를 가져오는 기능

- [ ] 모든 크루들의 닉네임을 수집한다.
- [ ] 크루의 출석 기록을 수집한다.

### 이용할 기능을 입력받는 기능

- [ ] `오늘 날짜`와 `기능 목록`을 출력한다.
- [ ] 선택할 기능에 대응되는 문자를 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] `1 ~ 4`또는 `Q`인지 검증한다.

### 출석 확인 기능

- [ ] `닉네임 입력 요청`을 출력한다.
- [ ] 크루 닉네임을 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] 존재하는 닉네임인지 검증한다.
- [ ] `등교 시각 입력 요청`을 출력한다.
- [ ] 등교 시각을 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] 입력 형식이 올바른지 검증한다.
    - [ ] `00:00`에서 `23:59` 이내의 범위인지 검증한다.
- [ ] 출석부에 해당 크루원의 출석을 기록한다.
- [ ] 오늘 날짜와 요일, 출석 시각, 출석 상태를 출력한다.

### 출석 기록 수정 기능

- [ ] `닉네임 입력 요청`을 출력한다.
- [ ] 크루 닉네임을 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] 존재하는 닉네임인지 검증한다.
- [ ] `수정 날짜 입력 요청`을 출력한다.
- [ ] 수정하려는 날짜를 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] `1 ~ 31` 범위의 숫자인지 검증한다.
- [ ] `수정 시각 입력 요청`을 출력한다.
- [ ] 수정할 출석 시각을 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] 입력 형식이 올바른지 검증한다.
    - [ ] `00:00`에서 `23:59` 이내의 범위인지 검증한다.
- [ ] 출석부에서 해당 크루원의 출석 기록을 수정한다.
- [ ] 기존 기록과 수정된 기록을 비교해 수정이 완료되었음을 출력한다.

### 크루별 출석 기록 확인 기능

- [ ] `닉네임 입력 요청`을 출력한다.
- [ ] 크루 닉네임을 입력받는다.
    - [ ] 빈 문자열이 아님을 검증한다.
    - [ ] 존재하는 닉네임인지 검증한다.
- [ ] 이번 달 해당 크루의 출석 기록 기본 문구를 출력한다.
- [ ] 출석부에서 해당 크루의 출석 기록을 가져와 모두 출력한다.
- [ ] 한 줄 개행 후, 출석/지각/결석 횟수를 출력한다.
- [ ] 제적 위험 대상자라면, 해당 위험 수준 대상자임을 출력한다.

### 제적 위험자 확인 기능

- [ ] 제적 위험자 조회 결과 기본 문구를 출력한다.
- [ ] 전 날까지의 기록을 바탕으로 제적 위험이 있는 크루들을 출석부에서 파악한다.
- [ ] 제적 위험순, 결석/지각 내림차순, 닉네임 오름차순으로 정렬한다.
- [ ] 크루의 닉네임과 결석 횟수, 지각 횟수, 위험 수준에 따른 조치를 출력한다.
