## 📝 구현할 기능 목록

### 주어진 날짜 및 시간 정보를 등록하는 기능

- [x] 출석 관리 객체에 운영 시간과 교육 시간을 등록한다.
    - [x] 월요일과 화~금요일 교육 시간을 분리해 등록한다.
- [x] `성탄절(12-25)`을 공휴일로 등록한다.

### CSV 파일에서 크루 정보와 출석 기록을 읽어와 등록하는 기능

- [x] `닉네임`과 `yyyy-mm-dd TT:mm`형식의 출석기록을 `,` 기준으로 추출
- [x] 읽은 닉네임과 출석 기록을 DTO로 반환
- [x] 닉네임 목록에서 중복을 제거해 Crew 목록을 생성한다.
    - [x] 크루의 출석 기록이 없는 경우 결석 `--:--`으로 등록한다.
- [x] 읽어온 출석 기록에서 크루 닉네임에 맞게 출석 기록을 등록한다.
- [x] 크루 목록을 일급 컬렉션으로 만든다.
- [x] 크루 목록을 출석 관리 객체에 등록한다.

### 출석 확인 기능

- [x] 닉네임과 등교시간을 입력받아 해당 크루의 출석 기록을 등록한다.
    - [x] 오늘이 주말이거나 공휴일인지 검증한다.
    - [x] 존재하는 닉네임인지 검증한다.
    - [x] 시간 형식 `HH:mm` 이 올바른지 검증한다.
    - [x] 해당 크루의 출석 기록이 이미 존재하는지 검증한다.
- [x] 크루의 출석 기록을 `mm월 dd일 w요일 HH:mm (출석 상태)`로 출력한다.

### 출석 수정 기능

- [x] 닉네임 날짜, 수정할 등교시간을 입력받아 출석 기록을 수정한다.
    - [x] 존재하는 닉네임인지 검증한다.
    - [x] 올바른 날짜 형식인지 검증한다.
    - [x] 미래 날짜가 아닌지 검증한다.
    - [x] 등교 시간 형식이 올바른지 검증한다.
- [x] 이전의 출석 기록과 최종 변경된 시각을 함께 출력한다.

### 크루별 출석 기록 확인 기능

- [ ] 닉네임을 입력받아 해당 크루의 어제까지 출석 기록을 출력한다.
    - [ ] 존재하는 닉네임인지 검증한다.
    - [ ] 결석일엔 `--:--`으로 시각을 표시한다. <= 출석 객체에서 String으로 시각 받아오는 메서드.
- [ ] 어제까지의 출석, 지각, 결석 횟수를 각각 출력한다.
- [ ] 지각, 결석이 일정 횟수를 넘었다면 어떤 대상인지 출력한다.

### 제적 위험자 확인 기능

- [ ] 전체 크루들 중에서 제적 위험자들을 출력한다.
    - [ ] 결석을 지각3회로 간주해 내림차순으로 출력한다. (지각 3회 == 결석 1회니까 이게 맞는 해석같음)
    - [ ] 출석 상태가 같다면 닉네임 오름차순으로 출력한다.

### 종료 기능

- [ ] 출석 관리 시스템을 종료한다.
